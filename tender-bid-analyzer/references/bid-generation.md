# 标书生成规则（Phase 2）

本文件定义标书结构合并、模板克隆、清洗与占位符规则。当前里程碑只实现“结构合并”，Word 组装待接入。

## 一、章节合并优先级

1. 招标文件要求优先：章节名称、顺序、层级以招标为准。
2. 递归下探：招标章节没有子项时，挂载用户模板的同义子树。
3. 模板优先：招标给了格式模板的章节，以招标模板块为准；用户同名内容转为补充说明。
4. 用户独有章节：追加到同层末尾。
5. 不适用章节：招标明确“不要求”的，直接省略，不生成空章节。
6. 术语统一：按招标用词统一“响应/投标”“成交/中标”。

## 二、Markdown 模板约定

| 写法 | 含义 |
|---|---|
| `> 提示：…` | 写作提示，不进标书，只进占位符清单 |
| `> 内容模板：路径` | 引用已有内容模板，插入标书 |
| 普通段落 | 固定正文，插入标书 |
| `[[…]]` | 未知字段占位符 |

章节内容解析顺序：

1. 招标格式模板
2. 用户 `内容模板`
3. 用户普通正文
4. 只有提示或无内容 → `[[待编写：章节名]]`

## 三、模板清洗

| 处理 | 对象 |
|---|---|
| 删 | “注：”“说明：”“备注：”“格式仅供参考”、操作指引、给投标人的提示 |
| 留 | 标题、表头、栏目标签、固定法律文本、签字盖章栏 |
| 空 | 表格内未知内容 |
| 填 | 表格外或表格内语义明确、值已知的字段 |

模板清洗必须生成 `template-cleanup.md`，记录每个模板块删除的内容，便于复核。

无法处理的情况：模板是图片、扫描件，或写“格式见附件”但附件缺失时，不强行克隆，插入 `[[按招标文件格式填写：XXX]]` 并列入风险。

## 四、占位符

| 类型 | 形式 | 用途 |
|---|---|---|
| 字段 | `[[字段名]]` | 表格外、信息未知的单个字段 |
| 附件 | `[[附件：名称]]` | 扫描件、证明材料的插入位置 |
| 章节 | `[[待编写：章节名]]` | 无模板、无内容模板的叙述性章节 |

盖章不设占位符，保留模板中的“（公章）”或空白盖章位。签字保留占位符：`[[法定代表人签字]]`、`[[授权代表签字]]`、`[[落款日期]]`。

## 五、表格

- 已知且语义明确的单元格：直接填真实值。
- 未知单元格：留空，不放占位符。
- 无标签的空白单元格：留空，不猜。
- 签字、盖章格：留空。
- 需要粘贴扫描件的单元格：允许 `[[附件：…]]`。
- 复杂表格必须从招标 DOCX 深拷贝 OOXML，不重画。
- 克隆后校验行数、网格列、列宽、`gridSpan`、`vMerge`。

## 六、真实信息

分析报告和标书都可以写入 C1/P1 的真实公司名、信用代码、法人、地址等。仍然只使用 `C1`、`P1` 作为配置文件名和内部选择代码。

## 七、输出文件

| 文件 | 内容 |
|---|---|
| `report.md` | 应标分析报告 |
| `bid.docx` | 标书正文（Phase 2） |
| `structure.md` | 章节结构及来源 |
| `structure.json` | 结构树 |
| `placeholders.md` | 字段、附件、章节占位符清单 |
| `template-cleanup.md` | 模板清洗记录 |
| `qa-bid.txt` | 标书校验结果 |
| `tender.json` | 招标文件结构化索引 |
| `timing.json` | 各阶段耗时 |

## 八、速度架构

- 脚本负责提取、结构合并、表格克隆、清洗、填充、组装、校验。
- 模型只负责语义判断（章节同义歧义、模板清洗歧义）和报告。
- 单次运行最多 3 次模型调用。
- 不生成叙述正文，只插入占位符。
- 不做 OCR；扫描件模板转附件占位符。
- 主链路不调用 LibreOffice。
- 同一招标文件按“文件哈希 + 包号 + 模板版本”缓存 `tender.json`、`structure.json`、模板块。

## 九、当前状态

- 已实现：`extract`（提取索引）、`structure`（章节合并）、`build`（模板块克隆、说明清理、已知字段填充、占位符插入、封面/目录/分页、标书校验）。
- 输出：`bid.docx`、`placeholders.md`、`template_cleanup.md`、`qa-bid.txt`。
- 入口：
  - `python3 scripts/run.py structure --root <工作区> --tender <文件> --package <包号> --template <模板>`
  - `python3 scripts/run.py build --root <工作区> --tender <文件> --package <包号> --company C1 --product P1`
- `build` 只读 `tender.json`、`structure.json`、Cx/Px 配置，不读 `report.md`；报告与标书两条链路可并行。
